## Contenido

| Archivo | Descripción |
|---|---|
| `ejercicio1_casa.py` | Casa estilizada (600 × 500) construida solo con `dda()` |
| `casa.png` | Imagen generada por el Ejercicio 1 |
| `ejercicio2_roseta.py` | Generador de rosetas geométricas con `bresenham()` |
| `roseta.png`, `roseta_12.png`, `roseta_24.png`, `roseta_36.png` | Rosetas con N = 24 (base), 12, 24 y 36 |
| `roseta_salto13.png` | Extensión: estrella {36/13}, solo puntos no adyacentes |
| `roseta_animada.gif` | Extensión: animación con N de 5 a 24 |

## Cómo ejecutar

Requisitos: Python 3.8+ y Pillow.

```bash
pip install pillow
python ejercicio1_casa.py
python ejercicio2_roseta.py
```

Las imágenes se generan en el directorio desde donde se ejecuta cada script.
